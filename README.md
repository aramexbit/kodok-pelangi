# Kodok Pelangi 🐸🌈

Game puzzle menembak bola ala Zuma — satu file HTML, jalan offline di browser.

## Cara main

- **Mouse**: arahkan untuk membidik, klik kiri untuk menembak
- **Sentuh layar**: geser untuk membidik, ketuk untuk menembak
- **Klik kanan / Spasi**: tukar bola yang dimuat dengan bola berikutnya
- **P**: jeda — **M**: bisu (atau tombol 🔊 di pojok kanan bawah)

Hancurkan 3+ bola warna sama sebelum rantai mencapai lubang. Level 1: 4 warna, 60 bola. Level 2: 5 warna, 80 bola, spiral dua putaran — menangkan level 2 untuk menang!

## Tentang

Rakitan final dari test agen (Grok vs ChatGPT vs DeepSeek): basis dari **DeepSeek**, ditambah fitur dari **ChatGPT** — dukungan sentuh, mute, layar peralihan level, dan getar layar saat ledakan. Semua visual digambar dengan kode canvas; suara via WebAudio; tanpa dependensi eksternal.

Main langsung: https://aramexbit.github.io/kodok-pelangi/
